# Guilherme Silva Portfolio

Portfólio pessoal com foco em apresentação profissional, tecnologias e projetos (incluindo dashboard Power BI).

## Estrutura

- `index.html`: página principal (apresentação, tecnologias, formações)
- `Projetos.html`: página de projetos/relatórios
- `index.js`: comportamento do menu mobile
- `css/style.css`: estilos globais
- `css/projetos.css`: ajustes visuais da página de projetos
- `img/`: imagens e assets do site

## Melhorias aplicadas

- Semântica HTML e estrutura válidas
- Melhorias de acessibilidade (skip link, ARIA no menu, foco visível)
- Metadados de SEO básicos
- Ajustes de responsividade e grid de cards
- Melhorias na estabilidade do menu mobile (fechamento por clique externo e tecla `Esc`)

## Como executar localmente

Como é um projeto estático, basta abrir `index.html` no navegador.

Se quiser usar servidor local:

1. No VS Code, abra a pasta do projeto.
2. Use a extensão Live Server **ou** execute um servidor HTTP local.
3. Acesse `index.html` no endereço servido.
